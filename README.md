# 🎮 Maze Solver Game

An interactive maze project built to explore **maze generation and pathfinding algorithms** using both web technologies and C++.

## ✨ Features

- 🎲 Random maze generation
- 🎮 Interactive web-based maze game
- ⌨️ Keyboard and on-screen controls
- 🔎 BFS shortest-path solving
- 🔎 DFS-based maze solving
- 🎆 Win animation
- 💻 C++ console implementation

## 🧠 Algorithms

- **BFS (Breadth-First Search)** — used to find the shortest path in the web version and C++ solver.
- **DFS (Depth-First Search)** — used for maze generation and pathfinding in the C++ version.

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- C++
- Data Structures & Algorithms
